## 🚀 Highlight Project

### ⏰ PS6 – Smart Alarm Clock for Arduino

An embedded system built using **Arduino Uno**, featuring:

* real-time clock (RTC)
* alarm scheduling with snooze functionality
* countdown timer
* temperature and humidity monitoring (DHT11)
* EEPROM-based persistence
* LCD interface

👉 See detailed documentation inside `PS6/README.md`
